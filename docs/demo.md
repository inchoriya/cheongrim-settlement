## 계정

비밀번호는 모두 `Demo1234!` 입니다.

| 역할 | 이메일 |
|------|--------|
| 관리자 | admin@cheongrim.local |
| 대행사 | agency@seoul.local |
| 가맹점 | merchant@kimbap.local |

## 추천 시연 순서 (약 5분)

1. **관리자**로 로그인 → 대시보드·수수료 정책 확인  
2. **정산**에서 기간 `2026-08-01` ~ `2026-08-08`으로 배치 실행  
3. 정산 상세에서 금액 분해 확인 후 **확정** → **지급 대기로**  
4. **지급** 실행 (Mock PG)  
5. **대행사**로 다시 로그인 → 주문·정산은 보이지만 지급·감사 로그 메뉴가 없는지 확인  
6. **가맹점**으로 로그인 → 김밥천국 건만 보이는지 확인  

시드 주문 `ORD-SEED-001`(20,000원) + `ORD-SEED-002`(10,001원)는  
기본 정책(플랫폼 5%, 대행 10%, 라이더 3,000원) 기준 가맹점 정산 합이 **19,501원**입니다.

## 영상 다시 찍기

백엔드·프론트가 떠 있는 상태에서:

```powershell
npm run demo:install
npm run demo:record
```
